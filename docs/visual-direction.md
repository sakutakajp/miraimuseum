# みらい博物館：ビジュアル方針

更新日：2026年10月16日

## 目指す質感

実写のような透明感と、精巧なミニチュアを手元で眺める感覚を持つ箱庭。参考画像から採るのはテイスト、素材感、光の質であり、崖・砂浜・植生などの配置や存在する物質は各題材に合わせて設計する。

## シリーズ共通の表現

- 角を丸めた正方形の台座・ブロックを基本形にする。場面ごとの地形は自由に変え、100個を同じシリーズに見せる。
- コンセプト画像は斜め上から全体を眺める視点を基本にし、箱庭の輪郭が切れない余白を取る。
- 背景は温かいアイボリーを基調にし、柔らかな方向光と自然な接地影で立体感を出す。
- 素材は細部まで触れられそうな質感にする。透明な水、鉱物、堆積物、細胞の膜などを描き分ける。
- 水が必要な場面では、透過、屈折、細かな水面の波、底に届く光の模様を見せる。題材に水域がなければ、水で囲う構成を必須にしない。
- 細胞などの微小な題材は、観察倍率を変えた模型として見せる。実景の海に巨大な細胞が存在する表現と混同させない。
- 参考画像の観光地らしい構図を全展示へ繰り返すことはせず、題材ごとに見せ場を決める。
- 画像本体には文字、番号、説明パネル、ロゴを入れず、番号・題名・説明は表示時に別の要素として添える。

これはコンセプト画像と制作時の見た目の指針。ゲーム中のカメラ、UI、各素材の実装方法は、操作性と描画負荷を確認しながら設計する。

## 初期の海と岩場

001は海を主役にし、水面下の地形を感じられる透明感を持たせる。002の岩場は砂や肌色に近い温かいベージュを基調にし、厚みのある不規則な塊として見せる。

岩には適度な凹凸を持たせ、ざらつきや細かすぎる起伏を抑える。山のような円錐形や整った球形を避け、灰色の頂部や、表面をミミズがはったように見える線をつくらない。水と岩の境目、波打ち際、岩の水中へのつながりを自然に見せる。

海底の熱水域、浅い池、微生物の場面では、その題材に合う素材へ変える。初期地球の場面に現代の植物、魚、サンゴなどを共通装飾として足さない。

これらの画像は会話内で作成した見た目の検討用の案。001〜004の水、光、台座の質感を005〜010へそろえ、題材に応じて観察スケールを変えた。

005は生命の成立をめぐる仮説の模型、008は細胞内部を見せる模型、009は多細胞のまとまりを見せる模型として扱う。003・004を一つの確定した生命誕生経路としてつなげない。007の地層や酸化の表現は、時間を圧縮した説明用の構成とする。

コンセプト画像の生成は3Dモデルの制作や歴史場面の実装の完了を示さない。各題材の考証は[構成案の参照資料](dioramas-100-overview.md)と[個別設計案](dioramas-100-details.md)に沿って進める。

# ローマ箱庭比較ラボ 開発計画

2026-10-13。既存 Nuxt 4.5.2 / Vue 3.5.43 / TypeScript 5.9.3 を維持する。
既存のホーム、恐竜ゲーム、採用方針を変更せず、`/lab` に独立実装する。

## 制作順

1. **画質** — Blender 4.3.2 の再生成可能なスクリプトでオリジナル GLB を作る。神殿の列柱・屋根瓦・ペディメント、水道橋のアーチ、石畳、市場、住宅、庭、川、舟、住民、積層台座。共通 HDR と PBR 材質を両エンジンで読み込み、同じ視点・昼夜・影条件で検証する。
2. **探索** — 純粋 TypeScript に配置、カメラ、入力、固定時間刻みの移動、障害物、経路探索、住民・風・舟のアニメーションを集約。Vue UI とキーボード、タッチ、仮想スティックを共有する。
3. **ゲーム** — 神殿・市場・港・水道橋・噴水の調査。共通の回転式水路パズルを解くと噴水と住民が反応する。ゲーム進行と視点をエンジン間で保存する。
4. **比較** — 比較Aと比較Bを明示。品質設定ごとに共通 DPR 上限、シャドウサイズを使用。FPSと描画統計は実測し、取得不能な値は「計測不可」。同じ条件の PNG と JSON を保存。比較ページでは保存した同一ブラウザの測定のみ表示する。
5. **検証** — 型検査、既存 Vitest、新規の経路・衝突・パズル・保存のテスト、Chromium WebGL2 の両エンジン操作、タッチ端末エミュレーション、ビルド、既存E2Eを実行。ソフトウェアGPUの値と実機未確認を区別してレポートへ記録する。

## 比較の境界

- 比較A: 同じアセット、投影、物体更新、固定解像度、PBR、環境、影、ゲーム。自動解像度変更は無効。
- 比較B: 同じ世界に各エンジンの AO / Bloom 等を追加。比較Aの実測と混ぜない。
- 60fps / 30fps は目標。ハードウェアGPU、iPhone Safari、Android Chromeの実測がない段階で達成とは記さない。
- 制作スクリプトは共通アセットのための Blender 処理。ブラウザでプリミティブを並べて世界を代用しない。
- 変更量は完成時のファイル行数と依存の変更を計測。作業時間は正確なエンジン別ログがないため推定しない。

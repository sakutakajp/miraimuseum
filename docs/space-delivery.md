# ねこの宇宙宅配便

URL: `/games/space-delivery/`。既存の博物館メニューとゲーム一覧データに入口を追加。シーザー暗号ゲーム・森ラン・トップの既存デザインは維持。

## 実行と操作

`npm ci` → `npm run dev`。下側のパッド中央を、飛ばす方向の逆へ引っ張って離す。角度・強さボタンと「とばす」も使用可能。キーボードはゲーム面にフォーカスした状態で左右が角度、上下が強さ、Spaceが発射、Rが再挑戦、Escapeが停止。ボタンなどへの入力とは競合しない。

飛行中も「もういちど」で即リセット。配送だけで次の配達が解放される。失敗した便の星は保存しない。博物館のBGMはゲーム中だけ一時停止し退出時に元の設定へ戻す。音・最高評価・解放・初回手の案内は独立したバージョン付きlocalStorageに保存。破損・保存不可でもプレイ可能。3回失敗で任意ヒントと長い予測を選べる。補助による評価減算なし。

## 構成

- `app/pages/games/space-delivery.vue`: ルート、クライアント専用の遅延ロード。
- `app/components/games/space-delivery/SpaceDeliveryGame.client.vue`: DOM操作・UI・ライフサイクル・保存接続。
- `app/game/space-delivery/physics.ts`: 描画非依存の純粋関数。XY、固定1/120秒、velocity Verlet、ソフトニング付き重力。線分上の配送・衝突・星・領域外・制限時間を発生順に処理。
- `runtime.ts`: 6状態、固定刻みのフレーム蓄積、予測、停止復帰、直前の軌跡、微調整の保持。
- `graphics.ts`: クライアント側の小さなCanvas図形描画。ドット密度を表示サイズに合わせ、文字はDOMに保持。
- `input.ts`: パッドから初速への変換、短い操作のキャンセル、上限。
- `DeliveryScene.ts`: 既存Babylon.js/SceneRuntimeの固定直交カメラ。惑星は軽量な立体球、船・ねこ・荷物・軌跡は自作の透過ドットレイヤー。盤面360×520を全体表示し、全レイヤーを標準約2 CSS pxの同じドット密度で描く。WebGL不可・コンテキスト消失時は同じ図形による軽量Canvas描画へ切り替えて遊べる。外部アセットなし。成功時はドッキング→荷物移動→ねこが喜ぶ。
- `stages.ts`: 6種類の配置と検証専用の基準解。04・06は星を取り切らない配送ルートと3つ星ルートを別に確保。
- `copy.ts` / `audio.ts` / `progress.ts`: 文字列、ユーザー操作後に開始する短い合成音、進捗。

このモデルは固定惑星による軌道の曲がりを体験する簡略化ゲーム。現実の太陽系や移動惑星によるスイングバイ加速の再現ではない。

## 検証

`npm run typecheck`、`npm test`、`npm run build`。ゲーム固有の純粋物理・状態・保存テストは `tests/space-delivery.test.ts`。

- 等速直線運動、引力方向への加速、決定性、予測と実飛行の一致。
- 30/60/120fpsの同一結果と大きいフレーム遅延の処理上限。
- 高速の線分判定、星→配送／衝突→配送のイベント順、領域外と時間切れ。
- 全6ステージの通常・3つ星基準解。各基準解の角度 −2/0/+2度、速度97/100/103%の9通り。飛行3〜12秒、星と惑星の安全距離。

ビルド後 `npx playwright test tests/browser/space-delivery.spec.ts tests/browser/museum.spec.ts` で実際のChromium上のマウスドラッグによる全6ステージの3つ星クリア、失敗・即リトライ、キーボード、タッチ、pointercancel、リサイズ、停止復帰、保存不可、再読み込み、再入場を確認。

360×640、390×844、430×932、844×390、1440×900でスクロールなし・盤面の縦横比・操作対象44px以上を確認。スクリーンショットでも縦横表示を点検。

## 検証範囲の制約

ブラウザ確認はLinux Chromiumとタッチエミュレーション。iPhone/Android実機の性能、Safari、実機での音の聞こえ方は未確認。UI文言は日本語で一か所に集約しているが英語版は未実装。初回スコープにログイン・オンライン・ランキングは含めない。

統合後の型チェック・本番ビルド成功、単体テスト16ファイル136件成功。宇宙ゲーム11件、既存博物館回帰4件、シーザーの音・保存不可回帰1件、計16件のブラウザ検証が成功。WebGL不可でも配達でき、3回の出入りで描画ループが1→0に戻り、ゲーム音が解放されて博物館BGMの以前の設定が復元されることも確認。

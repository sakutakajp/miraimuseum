# Floating Earth — Babylon.jsホーム

2026-10-09。黒い空間、中央の青い地球、白い雲と青い大気、左上のMIRAI MUSEUM、右上の言語、下の操作ヒントを維持する。画質選択を右上に追加する。

`FloatingEarthExperience.vue` はUIとルート、`FloatingEarthWorld.ts` はBabylonのScene、`earth-material.ts` は写真地球・雲影・海面反射・大気。GLBの軸傾斜と材質用テクスチャを利用し、Earthの回転クリップは再生しない。GLBのバイト・頂点・埋め込み画像は編集しない。Earthだけは球の中心、展示物は足元を原点に、親TransformNodeで縮尺・向きを補正する。

地球はゆっくり自転し、ドラッグ、ホイール、タップ、Enter / Space、矢印キー、Homeで操作する。7pxのドラッグしきい値を維持し、ドラッグ終了からゲームを開始しない。裏側の展示物は無効化する。可視メッシュへのray pickに地球を深度ブロッカーとして含め、雲・大気・光柱を選択対象から除く。タッチ10px / マウス6pxの許容を持つ。キーボード用ボタンは見えている実モデルの位置に配置する。

ブラキオサウルスは `dinosaur.glb`。サイズ0.5616、表面offset0.008。選択すると恐竜ランへ移動する。車は `cybertruck.glb`、同じ最大寸法、恐竜の法線と直交する大円上を走るため、地球を回しても恐竜と衝突しない。タイヤを球面へ接地し、元のテクスチャとPBR材質に小さなスタジオ反射を加え、シルバーを保つ。白い外側のシルエット発光はBabylonのHighlightLayerを使用し、内側の色を覆わない。

`reveal.ts` は恐竜と車で共通。1.2秒から光柱、1.95–2.95秒でモデルのフェードと拡大、3.5秒で落ち着く。reduced motionは光柱と拡大を省き、短いフェードにする。地球は読み込み・演出中も操作できる。車が解放されている場合、両モデルの準備後に同じ時計で演出を開始する。

車の条件は既存の `deep-time:v1.cleared` または共通v2の恐竜ステージclear。初めてclearして戻った時に出現し、同一訪問中は再クリアしても演出を繰り返さない。次回アクセスで既存のclearから再び光柱で出現する。選択は「次のゲームは開発中です。」の日英ダイアログのみ。レースの空Sceneは作らない。

自由の女神は提供された `statue-of-liberty-optimized.glb` をbyte-for-byteで追加した常設展示。恐竜と車から離れた位置、同じ最大寸法で親Transformだけを補正する。GLBの材質・テクスチャ・頂点を変更しない。解放条件・ゲームの起動先・光柱は持たない。読み込み失敗で他の展示を停止しない。

地球の読み込み / WebGL2失敗は静止画と直接ゲームリンクに戻す。展示モデルの失敗はその展示だけを unavailable にする。タブ非表示・退出・context lossでループとGPU素材を解放する。原本・地球の生成元・出典・Apacheライセンスは `public/floating-earth` と `public/landing-earth` に残す。

操作・画像・解放の確認結果は [検証記録](verification/babylon-migration.md)。iOS / Android実機は未検証。

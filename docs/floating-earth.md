# Floating Earth ホーム

現在の `/` は、黒い空間に鮮やかなローポリ地球が浮かぶホーム。以前のScene 00〜02のスクロール体験に代わり、参照画像の地球の形と色を優先する。博物館とゲームは引き続き `/museum` に置く。

## 見た目

- 海はコバルト／サファイアブルー、大陸は緑と黄土色。三角形ごとの色の変化で面を見せる。
- 白い雲を地表から浮かせ、青い大気のrimを加える。最初はアメリカ大陸が見える向き。
- 地球は静かに浮遊する。自動で回り続けず、利用者が触れたときに回る。
- ヘッダーにはブランドと「博物館へ」を置き、地球を主役にする。

## 操作

| 入力 | 動作 |
| --- | --- |
| タップ／クリック | 地球を回す |
| 指／マウスのドラッグ | 横方向と縦方向の向きを変える |
| 矢印キー | 向きを少しずつ変える |
| Enter／Space | 地球を回す |
| Home | 最初の向きに戻す |

地球の操作領域はフォーカスできるボタンとして提供する。操作はその領域の中に限定し、博物館へのリンクやキーボードの通常のフォーカス移動を妨げない。

`prefers-reduced-motion: reduce` では浮遊と慣性による動きを停止し、タップ・ドラッグ・キーボードによる明示的な回転は維持する。タップはその場で向きを切り替える。

## 描画とfallback

- ページ内のThree.js Canvasは1つ。地球の回転や画面サイズ変更でCanvasを作り直さない。
- 地球モデルはローカルの `/floating-earth/model.json` から読み込む。
- スマートフォンの縦横画面とウィンドウサイズ変更に合わせ、地球が画面内に収まるように構図を調整する。
- 品質は端末と描画の負荷に応じて調整する。バックグラウンドでは更新を停止する。
- WebGLを利用できない場合、モデルの読み込みに失敗した場合、WebGL contextを失った場合は、`/floating-earth/earth.svg` を表示する。
- 静止画のfallbackでは3D操作を無効にする。JavaScript無効でも地球と「博物館へ」はサーバーから出力され、入館できる。

## 検証

`tests/browser/landing.spec.ts` は現在の地球ホームを対象にする。タップ、ドラッグ、キーボード、実際のtouch入力、縦横画面の変更、reduced-motion、バックグラウンドの停止と復帰、WebGL・モデル読み込みの失敗、context loss、モデル読み込み中のcontext loss後に描画が復活しないこと、JavaScript無効時を確認する。既存ゲームの回帰確認は `tests/browser/v2.spec.ts` に保持する。

```sh
npm run typecheck
npm test
npm run build
npx playwright test
```

旧ランディングの仕様と実装は履歴として保持するが、ホームから起動しない。ゲームの起動、ゲーム中の操作、スコア、端末保存の仕様は変更しない。

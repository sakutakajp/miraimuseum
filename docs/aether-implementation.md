# AETHER — 水風の遺跡

陽光の中に残る石造遺跡、青緑の川、滝、樹木と蔦を探索する小さな3Dゲーム。Babylon.js 8.56.2 / TypeScript / Nuxt 4.5.2。

## 起動

`/aether` を開く。トップページ `/` は既存の「開発中」表示を維持する。本番実行は `npm run build` → `npm run preview`。

Node.js 22.19以降（24推奨）。

```sh
npm ci
npm run dev
```

表示されたURLを開く。本番実行は `npm run build` → `npm run preview`。

```sh
npm run typecheck
npm run generate
```

静的生成物は `.output/public`。

## 操作

PCはWASDで移動、ドラッグと矢印キーで見渡す、ホイールで拡大縮小、Shiftで速く歩く。タッチ端末は左のパッドで移動、画面をドラッグして見渡す。祭壇の近くでEまたは「灯をともす」を押す。祭壇3つで完了。Escまたは休止ボタンで休止、設定から再開・リセット・画質変更。

## 表現と実装

専用の面取り石材・アーチの迫石・溝のある柱・段状の断崖を組み合わせ、静的形状を材質ごとに結合する。樹冠と蔦の葉はGPUインスタンス。3Dの探索者は歩行に合わせて動き、カメラは滑らかに追従する。

PBR、事前加工したCC0 HDR環境光、暖かな方向光、PCF影、ACES、Bloom、FXAA/MSAA、距離霧、粒子を使用。水面には反射、岸辺の泡、波紋とカースティクスを近似するシェーダー。滝は動く水流と水しぶきで描く。高品質かつ描画が安定したPCでは被写界深度を追加する。

モバイルの初期設定は8bitの反射、512pxの影、1x以下の解像度、MSAAと被写界深度なし。16bitインデックスを使用し、WebGL 1と浮動小数点・32bitインデックス拡張なしでも起動する。起動に失敗した場合はWebGL 1設定で一度だけ自動再試行し、手動再試行とエラー情報も提供する。`?compat=1` で最初から互換設定を使用できる。

クライアント専用コンポーネントと遅延importでSSRから分離。非表示タブでは描画と音を止め、アンマウント時に入力、描画ループ、音、Scene、Engineを破棄する。

## 検証と制約

Chromiumの実描画とiPhone相当の画面・タッチ入力で、移動、カメラ、祭壇3つ、完了、休止・再開、回転、リセット、互換描画、画質とリソース破棄を確認。実GPUの60fps計測とiPhone実機Safariの確認は未実施。水と滝は表現の近似であり、物理流体ではない。

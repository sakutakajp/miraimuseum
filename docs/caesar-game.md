# ひだまりの部屋：暗号ゲーム

現在の体験は黒猫ルゥとローマの住宅です。旧「暗号の遺跡」「ミイとコロ」「橋・通信機」の実装仕様を置き換えます。トップの「はいる」から `/games/caesar/` へ直接進み、ルゥが日なたで眠るために扉の仕掛けを解きます。展示室、読み上げはありません。

## 問題の段階

| 段階 | 入力 | 結果 | 求めること |
| --- | --- | --- | --- |
| まず1つ | い | あ | 戻すボタンを1回押す。採点対象外 |
| 一緒に動く | うお | いえ | 2文字が同時に1つ戻る。採点対象外 |
| 手前の扉 | さのさ | こねこ | 3文字全体を1つ戻して合言葉へ。採点対象外 |
| 文字の輪 | ん / あ | あ / ん | 境界と反対向きの戻し。採点対象外 |
| 奥の扉のお手本 | あ → う | 移動0→1→2 | 始点を数えず、移動を数える。採点対象外 |
| 予測 | か、お手本あ→う | く | 盤面を動かす前に3択で答える |
| 日なたの時間 | へろ、お手本あ→う | ひる | 新しい鍵で2つ戻す |
| 最後の合言葉 | くかと、お手本あ→え | おうち | 別の鍵を考えて3つ戻す |

すべての変換を実際の `shiftWord` で検証します。元の文字と変化した文字は上下2段で同時表示し、各対応は色だけでなく矢印と枠で示します。予測・設定中の結果は「？」のままです。方向→数→実行を同じ操作領域で切り替え、選び直しても数を保持します。数は＋／−で1ずつ循環。減点や強制リセットはありません。

初期の練習では近くの6文字の順序を表示し、後から46文字の循環を導入します。すべての文字は共通の数で変化します。ボタンを必ず設け、練習2・3では右ドラッグで1つ戻す／左ドラッグで1つ進める操作も使えます。1セル60px、1ドラッグ最大2つ。文字盤の左右キーも同じ向きです。縦スワイプは無理に取りません。主操作はTab・Enterでも完了できます。

ヒントは注目箇所→1文字の例→実演ダイアログ。問題の選択を変えずに閉じられます。成功後は入力を止め、短い反応を見て利用者が「つぎへ」を押します。切り替え直後と成功直後の連打は状態機械で抑制します。背景・扉・眠る猫の状態で達成を伝えます。

## 共通の文字と保存

```
あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろわをん
```

46文字。`を`を含み、`ん`の次は`あ`。空欄、濁音、小さい文字を数に含めません。表示表と計算は `cipher.ts` の同じ定義を使います。変換は `((index + shift) % 46 + 46) % 46`、正数は進む・負数は戻す。同値の43進む＝3戻す、44進む＝2戻すも正解です。

保存キーは `mirai-museum:caesar:v3`、教材ID `ru-sunny-1`。予測・解読3問にだけ初回正誤、累計試行回数、最大ヒント段階、正解状況を保存します。ガイド付き練習を理解判定に混ぜません。`mirai-museum:naps:v1` に2種類の寝床と訪問回数を保存します。破損・未知ID・古い教材・不整合なクリア記録を検証し、保存が拒否されても遊べます。別端末への同期はありません。

歴史と創作、素材、画面については [最新仕様](museum-renewal.md)、実際の確認範囲は [検証記録](verification/museum-renewal.md) を参照してください。

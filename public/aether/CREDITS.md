AETHER — 水風の遺跡

All ruins, rocks, trees, leaves, character, shaders, generated surface textures, interface and synthesized audio were created for this project. No external 3D models or sound recordings are used.
The visual direction was developed from the reference image supplied in the conversation. That image is not used as a background or game texture.

HDR lighting: Royal Esplanade, Greg Zaal / Poly Haven (originally HDRI Haven), CC0 1.0 Universal.
Source: https://polyhaven.com/a/royal_esplanade
Distributed copy: https://github.com/mrdoob/three.js/blob/r170/examples/textures/equirectangular/royal_esplanade_1k.hdr
License: https://polyhaven.com/license and https://creativecommons.org/publicdomain/zero/1.0/

royal-esplanade.env is a prefiltered RGBD environment derived from the same CC0 HDR, prepared once with Babylon.js. It avoids runtime HDR conversion and 4096-sample GPU filtering on phones.

Babylon.js: Apache License 2.0. https://github.com/BabylonJS/Babylon.js
